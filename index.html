数2 基礎練習問題

三角関数・指数・対数関数

対象：県立通信制高校 レベル：基本〜標準 問題数：各単元5問

1三角関数

弧度法、三角関数の値、加法定理、三角方程式の基本問題です。公式を確認しながら丁寧に解いてください。

問1 弧度法

次の角度を、度数法（度）から弧度法（ラジアン）に変換しなさい。

（1）60°　（2）135°　（3）-30°

解答

（1）60° = π3　（2）135° = 3π4　（3）-30° = -π6

ヒント：180° = π [rad] を基準に、比例して変換します。
問2 三角関数の値

次の三角関数の値を求めなさい。

（1）sin 2π3　（2）cos 7π6　（3）tan 3π4

解答

（1）sin 2π3 = √32

（2）cos 7π6 = -√32

（3）tan 3π4 = -1

ヒント：単位円で考えて、象限に注意しましょう。第2象限では sin > 0、cos < 0 です。
問3 加法定理

sin(α + β) = sin α cos β + cos α sin β を使って、sin 75° の値を求めなさい。

解答

sin 75° = sin(45° + 30°)

= sin 45° cos 30° + cos 45° sin 30°

= √22 × √32 + √22 × 12

= √64 + √24 = √6 + √24

ヒント：75° = 45° + 30° と分解して、既知の角度の値を使います。
問4 三角方程式

0 ≤ θ < 2π の範囲で、次の方程式を解きなさい。

（1）2 sin θ - 1 = 0　（2）cos θ = -12

解答

（1）sin θ = 12　より　θ = π6 , 5π6

（2）cos θ = -12　より　θ = 2π3 , 4π3

ヒント：sin θ = a の解は単位円で y = a の直線との交点を探します。cos は x 座標に注目しましょう。
5 三角関数の合成

sin θ + √3 cos θ を r sin(θ + α) （r > 0, 0 ≤ α < 2π）の形に変形しなさい。

解答

r = √(1² + (√3)²) = √4 = 2

cos α = 12 ,　sin α = √32　より　α = π3

したがって　sin θ + √3 cos θ = 2 sin(θ + π3)

ヒント：r = √(a² + b²) を先に求め、cos α = ar , sin α = br から α を定めます。

2指数・対数関数

指数法則、対数の性質、指数方程式・対数方程式の基本問題です。計算の手順を一つずつ確認しながら進めてください。

問1 指数法則

次の式を計算しない。

（1）2³ × 2⁻² ÷ 2⁻¹　（2）(3²)³ ÷ 3⁴　（3）823

解答

（1）2³ × 2⁻² ÷ 2⁻¹ = 23 + (-2) - (-1) = 2² = 4

（2）(3²)³ ÷ 3⁴ = 3⁶ ÷ 3⁴ = 3² = 9

（3）823 = (2³)23 = 2² = 4

ヒント：am × an = am+n、am ÷ an = am-n、(am)n = amn を確認しましょう。
問2 対数の性質

log₁₀ 2 = 0.301、log₁₀ 3 = 0.477 のとき、次の値を求めなさい。

（1）log₁₀ 6　（2）log₁₀ 12　（3）log₁₀ √5

解答

（1）log₁₀ 6 = log₁₀(2 × 3) = log₁₀ 2 + log₁₀ 3 = 0.301 + 0.477 = 0.778

（2）log₁₀ 12 = log₁₀(2² × 3) = 2 log₁₀ 2 + log₁₀ 3 = 2 × 0.301 + 0.477 = 1.079

（3）log₁₀ √5 = 12 log₁₀ 5 = 12 log₁₀ 102 = 12(1 - 0.301) = 0.3495

ヒント：log(ab) = log a + log b、log(a/b) = log a - log b、log aⁿ = n log a を使います。√5 = 512 です。
問3 対数の定義

次の対数を求めなさい。

（1）log₂ 32　（2）log₃ 19　（3）log₅ √125

解答

（1）2⁵ = 32 より　log₂ 32 = 5

（2）3⁻² = 19 より　log₃ 19 = -2

（3）√125 = 12512 = (5³)12 = 532　より　log₅ √125 = 32

ヒント：loga b = c ⇔ ac = b です。まず「何乗すれば…」と考えましょう。
問4 指数方程式

次の方程式を解きなさい。

（1）3x = 81　（2）22x-1 = 132

解答

（1）81 = 3⁴ より　3x = 3⁴　したがって　x = 4

（2）132 = 12⁵ = 2⁻⁵ より　22x-1 = 2⁻⁵

2x - 1 = -5　より　2x = -4　したがって　x = -2

ヒント：両辺を同じ底のべきにそろえて、指数部分を等しくします。
問5 対数方程式

次の方程式を解きなさい。

（1）log₂ x = 5　（2）log₃(x - 1) = 2　（3）log₂(x + 3) + log₂(x - 1) = log₂ 5

解答

（1）log₂ x = 5 より　x = 2⁵ = 32

（2）log₃(x - 1) = 2 より　x - 1 = 3² = 9　したがって　x = 10

（3）log₂(x + 3)(x - 1) = log₂ 5 より　(x + 3)(x - 1) = 5

x² + 2x - 3 = 5　より　x² + 2x - 8 = 0

(x + 4)(x - 2) = 0　より　x = -4, 2

真数条件より x > 1 なので　x = 2

ヒント：（3）は log a + log b = log(ab) を使います。最後に必ず真数条件（log の中身 > 0）を確認しましょう。
